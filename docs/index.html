What this page can tell you

These checks exercise real ShiurBank requests, including audio and small private test uploads. Most run about every five minutes; downloads run every 15 minutes and uploads every hour. Two failed scheduled observations confirm an outage; two successful observations confirm recovery.

Checks run from one external location. Scheduling can be delayed. Missing or old observations show as unknown. A successful check does not guarantee every device, network, account or file is working. App crashes, offline mode and background playback require separate device testing.

This page and its observation history are hosted separately from ShiurBank’s website, API, database and audio storage.
